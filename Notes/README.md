# Notes — Simple Guide

Use this folder for **theory and interview revision**.  
Use `../DSA/` for **coding practice** (problems + Java).

```text
Notes/
├── Interview/           ← job prep checklists + question bank
├── DSA_CheatSheets/     ← deep DSA pattern explanations
└── SystemDesign/        ← architecture layers (1 → 11)
```

---

## What to open when

| Goal | Open |
|---|---|
| Practice coding a pattern | `../DSA/<Pattern>/` |
| Understand a pattern deeply | `DSA_CheatSheets/` |
| Java/backend interview theory | `Interview/` |
| System design / architecture | `SystemDesign/` |

---

## Suggested order

### 1) Interview prep
1. `Interview/Arrise_SDE2_Prep.md` — topic map  
2. `Interview/Java_Backend_Interview_Question_Bank.md` — questions  
3. `Interview/Interview_Evaluation_Topics.txt` — evaluation checklist  

### 2) DSA deep revision (after practising in `DSA/`)
1. `DSA_CheatSheets/DSA_Master_Cheat_Sheet.md` — how to recognise patterns  
2. Then one cheat sheet at a time (Two Pointers → … → Graphs/DP)  

### 3) System design
1. `SystemDesign/00_Platform_Blueprint.md`  
2. Then layers `01` → `11` in order  

---

## Simple rule

> **Learn by doing in `DSA/`.  
> Revise “why” in `Notes/`.**
